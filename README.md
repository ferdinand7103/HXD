# Manlingua 
Apple Developer Academy Group Project by Hao Xiong Di 好兄弟 | 1 Month


### Solution Concept
An iOS Mandarin learning app for beginners to master everyday conversations in Mandarin, using learning methods based on the Cambridge Mandarin Syllabus and interactive story-based conversations.

### Tech Stack
SwiftUI, UIKit, AVFoundation, HuggingFace

### App Features
1. **Start with Character Introduction**
    
    Learners begin with the basics, focusing on pronunciation and tones. Characters are broken down into simple syllables, making it easier to understand and pronounce correctly.
    
2. **Reinforce with Flashcards**
    
    To build vocabulary and pronunciation skills, MANLINGUA uses flashcards that help reinforce what learners have just studied. This method makes it easier to memorize words and tones.
    
3. **Test Understanding**
    
    Through various quizzes and questions, learners can test their understanding of the material, ensuring they grasp the key concepts before moving forward.
    
4. **Conversation Practice**
    
    The app encourages learners to practice speaking by using sentences derived from the flashcards. This hands-on practice helps overcome the challenges of speaking Mandarin in real-life scenarios, boosting confidence and fluency.
